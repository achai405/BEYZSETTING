# BEYZ STORE — Starter Website

Ini ialah prototaip front-end awal BEYZ untuk diuji melalui telefon.

## Fail
- `index.html` — struktur halaman
- `style.css` — reka bentuk responsive dan warna tema
- `app.js` — katalog contoh, modal produk, menu dan interaksi prototaip

## Cara guna dengan GitHub
1. Buat repository baru bernama `beyz-store`.
2. Upload ketiga-tiga fail ke bahagian utama repository (root).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, kemudian Save.
6. Tunggu GitHub Pages keluarkan URL website.

## Penting
Versi ini ialah prototaip paparan. Ia BELUM menyimpan pesanan atau redeem code, belum mempunyai login admin sebenar, belum memproses bayaran, dan belum memuat naik resit. Jangan masukkan QR atau nombor bank sebenar ke dalam fail awam. Fasa seterusnya ialah sambungkan Firebase (Authentication, Firestore dan Storage), tetapkan role owner/admin dengan rules keselamatan, dan bina pengurusan produk/pesanan.

Semua nama produk dan harga yang dipaparkan ialah contoh dan perlu diganti.
